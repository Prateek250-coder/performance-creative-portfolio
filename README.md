# Performance Creative Portfolio

A responsive portfolio website for AI-assisted video and performance creative samples.

## Preview locally
Open `index.html` in a browser.

## Add the video samples
Upload these two MP4 files to the repository root, beside `index.html`, using the exact filenames:
- `seekho app trial.mp4`
- `Ad-Saksham Sample.mp4`

The portfolio HTML already points to these filenames. GitHub's regular web uploader has a 25 MB per-file limit; both compressed video samples are below that limit.

## Publish with GitHub Pages
Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then click **Save**.

The site address will be: https://prateek250-coder.github.io/performance-creative-portfolio/

## Accuracy note
The videos are presented as creative production samples, not verified paid-ad campaigns. No ROAS, CPA, conversion, or revenue results are claimed.
